THE FIRST FIVE MINUTES

A good start
is a simple one.

Here's everything you need to make your first embroidery artwork in the web studio.

01

Start with a shape

Open Studio. Pick the rectangle, ellipse, line, freehand or text tool. Draw directly on the canvas.

□ ⬭ ╱
02

Make it yours

Tap a shape to select it. Drag to move. Adjust color, stroke, dimensions and name in the properties panel.

◌ → ◉
03

Preview the texture

Toggle Stitch view to see an approximate on-screen texture. This is a visual preview, not machine digitization.

≋ ≋ ≋
04

Save and continue

Export SVG to open in Hooop desktop. Use the native desktop editor to generate embroidery machine files and connect Bluetooth devices.

↓ .SVG
Browser vs desktop

The web edition offers SVG composition, imports, edits, local autosave, stitch visualization and SVG/PNG exports. Full PES/DST/EXP/JEF/VP3 production output, MCP and Brother Skitch pairing stay in the Rust desktop app.
